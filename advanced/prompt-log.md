# 프롬프트 로그 뷰어

번역 과정에서 AI에게 전송된 프롬프트와 응답을 확인할 수 있는 디버깅 도구입니다.

---

## 접근 방법

1. 소설 상세 화면 진입
2. 상단 메뉴(⋮) > **프롬프트 로그** 선택

---

## 용도

- 번역 품질이 기대와 다를 때 실제 전송된 프롬프트 확인
- 컨텍스트(캐릭터, 용어 등)가 제대로 포함되었는지 검증
- 토큰 사용량 확인 (입력/출력 토큰 수 표시)

---

## 기본 사용법

### 탭 구분

| 탭 | 내용 |
|-----|------|
| **번역** | 번역 요청/응답 로그 |
| **필터** | 컨텍스트 필터링 관련 로그 |

### 주요 기능

| 기능 | 설명 |
|------|------|
| **검색** | 로그 내용에서 키워드 검색 |
| **복사** | 로그 내용을 클립보드에 복사 |
| **공유** | 외부 앱으로 로그 공유 |
| **삭제** | 선택한 로그 삭제 |

### 로그 정보

각 로그 항목에는 다음 정보가 포함됩니다:

- 회차 번호
- 요청 시간
- 입력/출력 토큰 수
- 전송된 프롬프트 전문
- AI 응답 전문

---

## 활용 팁

- 번역이 이상할 때 해당 회차의 프롬프트 로그를 확인하면 원인을 파악할 수 있습니다
- 커스텀 프롬프트를 테스트할 때 실제 적용 여부를 로그에서 확인하세요
- 토큰 수를 확인하여 비용 최적화에 활용하세요
