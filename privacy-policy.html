Transy (데브랜 / devran)(이하 "앱")는 사용자의 개인정보를 중요하게 생각하며, 관련 법령을 준수합니다. 본 개인정보처리방침은 앱이 수집하는 정보와 그 사용 방법에 대해 설명합니다.

database

1. 수집하는 정보

1.1 사용자가 직접 제공하는 정보

정보 유형 설명 저장 위치
Gemini API 키 번역 기능 사용을 위해 사용자가 직접 입력 기기 로컬 저장소 (암호화)
소설 URL 사용자가 추가한 웹소설 주소 기기 로컬 저장소
앱 설정 폰트 크기, TTS 설정 등 사용자 환경설정 기기 로컬 저장소
info 중요: 위 정보는 모두 사용자의 기기에만 저장되며, 개발자 서버로 전송되지 않습니다.

1.2 자동으로 수집되는 정보

정보 유형 목적 수집 주체

광고 ID 맞춤형 광고 제공 Google AdMob

앱은 다음 정보를 수집하지 않습니다:

Transy (데브랜 / devran) is a web novel translation app that uses AI (Google Gemini) to translate foreign novels into Korean. We are committed to protecting your privacy and complying with applicable laws.

1. Information We Collect

1.1 User-Provided Information

Type Description Storage
Gemini API Key Entered directly by the user to enable translation features Local device storage (encrypted)
Novel URLs Web novel addresses added by the user Local device storage
App Settings User preferences such as font size, TTS settings Local device storage
info Important: All of the above information is stored only on the user's device and is never transmitted to developer servers.

1.2 Automatically Collected Information

Type Purpose Collected By
