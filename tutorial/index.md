# Transy 시작하기

처음 오셨군요! 반가워요.

이 튜토리얼을 따라하면 **10분 안에** 첫 번째 소설을 가져와서 읽을 수 있어요.

---

## 튜토리얼 순서

### [Step 1. API 키 설정하기](api-setup/)
Transy가 번역을 하려면 AI가 필요해요. Gemini API 키를 발급받고 앱에 등록하는 방법을 알려드릴게요.

### [Step 2. 파싱 룰 만들기](parsing-rule/)
새로운 소설 사이트를 Transy에 등록하는 방법이에요. AI가 자동으로 분석해주니까 어렵지 않아요!

### [Step 3. 소설 가져오기](import-novel/)
드디어 소설을 가져올 차례예요.

### [Step 4. 소설 읽고 번역하기](read-and-translate/)
가져온 소설을 열어서 첫 번역을 해볼게요. 설정 방법도 알려드릴게요!

> **파일(EPUB/TXT)이나 텍스트로 시작하시나요?**
> 파싱 룰이 필요 없으므로 **Step 1 → Step 4**로 바로 진행할 수 있어요!
> - [파일로 소설 추가](../novel-management/add-novel-file.md)
> - [텍스트 직접 입력](../novel-management/add-novel-text.md)
