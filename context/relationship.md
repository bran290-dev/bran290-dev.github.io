# 관계 관리

캐릭터 간의 관계를 관리합니다.

---

## 관계란?

두 캐릭터 사이의 관계 정보입니다. 관계 유형, 친밀도, 호칭 등을 저장합니다.

---

## 관계 목록

### 표시 정보

| 항목 | 설명 |
|------|------|
| 캐릭터 | 관계를 맺은 두 캐릭터 |
| 관계 유형 | 친구, 연인, 라이벌 등 |
| 친밀도 | 0-100 사이의 수치 |
| 호칭 | 서로를 부르는 호칭 |
| 설명 | 관계에 대한 추가 설명 |
| 회차 | 마지막으로 수정된 회차 |

## 관계 추가

### 추가 방법

1. 관계 탭에서 "+" 버튼 클릭
2. 정보 입력
3. 저장

### 입력 필드

| 필드 | 필수 | 설명 |
|------|------|------|
| 캐릭터 A | 필수 | 첫 번째 캐릭터 선택 |
| 캐릭터 B | 필수 | 두 번째 캐릭터 선택 |
| 관계 유형 | 필수 | 관계 종류 선택 |
| 친밀도 | 선택 | 0-100 (기본값: 50) |
| A→B 호칭 | 선택 | A가 B를 부르는 호칭 |
| B→A 호칭 | 선택 | B가 A를 부르는 호칭 |
| 설명 | 선택 | 관계에 대한 추가 설명 |

### 호칭 예시

```
캐릭터 A: 다나카
캐릭터 B: 사쿠라
관계 유형: 사제관계
A→B 호칭: 제자, 사쿠라
B→A 호칭: 스승님, 선생님
```

## 자동 추출

번역 과정에서 AI가 캐릭터 간 관계를 자동으로 감지합니다.

### 동작

1. 번역 중 관계 정보 감지
2. 관계 유형, 친밀도 추정
3. 호칭 정보 추출
4. 자동 등록

---

## 관계 편집

### 편집 방법

1. 관계 항목의 편집 버튼 클릭
2. 정보 수정
3. 저장

### 수정 가능 항목

- 관계 유형
- 친밀도
- 호칭
- 설명

> **참고**: 캐릭터는 수정할 수 없습니다. 다른 캐릭터 간 관계가 필요하면 새로 추가하세요.

### 업데이트 범위

수정 시 적용 범위를 선택할 수 있습니다.

| 범위 | 설명 |
|------|------|
| 현재 회차만 | 현재 회차의 정보만 수정 |
| 이후 회차도 | 현재 회차와 이후 회차도 함께 수정 |
| 전체 회차 | 모든 회차의 정보 수정 |

---

## 관계 삭제

### 삭제 방법

1. 관계 항목에서 삭제 버튼 클릭
2. 확인 후 삭제

---

## 문제 해결

### 같은 관계가 중복 등록됨

**해결**:
1. 하나만 남기고 삭제
2. 자동 추출과 수동 등록이 겹친 경우일 수 있음

### 호칭이 번역에 반영 안 됨

**확인**:
1. 호칭 필드가 비어있지 않은지 확인
2. 캐릭터가 올바르게 연결되어 있는지 확인
