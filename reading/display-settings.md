# 디스플레이 설정

뷰어의 텍스트 표시 및 화면 설정을 조정하는 방법입니다.

---

## 설정 접근

뷰어 화면에서 설정 버튼(⚙️)을 클릭합니다.

---

## 폰트 설정

### 폰트 크기

텍스트 크기를 조절합니다.

| 크기 | 용도 |
|------|------|
| 12-14sp | 작은 화면, 많은 텍스트 |
| 16-18sp | 일반 읽기 (권장) |
| 20-24sp | 큰 글씨 선호, 눈 피로 감소 |

### 폰트 패밀리

사용할 폰트를 선택합니다.

| 옵션 | 설명 |
|------|------|
| 기본 | 시스템 기본 폰트 |
| 나눔고딕 | 깔끔한 고딕체 (산세리프) |
| 고운돋움 | 부드러운 둥근 돋움체 |
| 나눔명조 | 출판물 느낌 바탕체 (세리프) |
| 고운바탕 | 부드러운 바탕체 |

### 내 폰트

기본 제공 폰트 외에 원하는 폰트를 직접 등록하여 사용할 수 있습니다.

**폰트 추가 방법**:
1. 폰트 패밀리 목록 하단의 "폰트 추가" 버튼을 클릭합니다.
2. 기기에 저장된 폰트 파일을 선택합니다.
3. 등록된 폰트가 목록에 표시됩니다.

**사용자 폰트 선택/삭제**:
- 등록된 폰트를 탭하면 바로 적용됩니다.
- 삭제하려면 해당 폰트 옆의 삭제 버튼을 클릭합니다.

> **지원 형식**: TTF, OTF 파일을 지원합니다.

### 폰트 굵기

텍스트의 굵기를 조절합니다.

| 옵션 | 설명 |
|------|------|
| 가벼움 | 얇은 굵기 |
| 보통 | 일반 (기본) |
| 중간 | 중간 굵기 |
| 굵게 | 굵은 굵기 |

### 텍스트 색상

배경에 따라 텍스트 색상을 조절합니다.

| 모드 | 설명 |
|------|------|
| AUTO | 배경에 맞춰 자동 설정 (기본) |
| DARK | 어두운 텍스트 (밝은 배경용) |
| LIGHT | 밝은 텍스트 (어두운 배경용) |

> **팁**: 대부분의 경우 AUTO로 두면 배경 텍스처에 맞는 색상이 자동으로 적용됩니다.

---

## 간격 설정

### 줄 간격

줄 사이의 간격을 조절합니다.

| 값 | 설명 |
|------|------|
| 1.0 | 촘촘함 |
| 1.5 | 일반 (기본) |
| 2.0 | 넓음 |

> **팁**: 줄 간격이 넓으면 가독성이 좋지만 스크롤이 많아집니다.

### 문단 간격

문단 사이의 간격을 조절합니다.

| 옵션 | 설명 |
|------|------|
| 좁게 | 최소 간격 |
| 보통 | 일반 (기본) |
| 넓게 | 넓은 간격 |

## 배경 설정

뷰어의 배경을 취향에 맞게 꾸밀 수 있습니다.

### 배경 타입

| 타입 | 설명 |
|------|------|
| 시스템 색상 | 시스템 테마(라이트/다크)에 따른 기본 배경 |
| 번들 텍스처 | 앱에 내장된 30종의 배경 이미지 |
| 커스텀 이미지 | 기기에 저장된 이미지를 배경으로 사용 |

### 번들 텍스처

총 30종의 배경 텍스처가 내장되어 있습니다.

| 카테고리 | 종류 |
|----------|------|
| 종이 | 밝은 종이, 따뜻한 종이, 고풍 양피지, 빈티지 종이, 아이보리 종이, 흰 종이, 캔버스 종이, 크림 빈티지, 크래프트, 갈색 종이, 양피지 |
| 나무 | 다크 우드, 러스틱 나무, 밝은 원목, 에이지드 다크 우드, 다크 우드(사진), 다크 우드 배경, 밝은 나무, 브라운 우드 |
| 한지 | 한지, 검은 한지, 노란 한지 |
| 패브릭 | 린넨, 크림 리넨, 베이지 패브릭, 샌드 패브릭, 자연 리넨 |
| 컬러 | 피치, 무지개, 브릭 |

> **팁**: 종이와 한지 계열은 소설 읽기에 특히 잘 어울립니다.

### 배경 스케일 모드

이미지 배경(번들 텍스처 또는 커스텀 이미지)을 선택하면 스케일 모드를 설정할 수 있습니다.

| 모드 | 설명 |
|------|------|
| CENTER_CROP | 화면을 가득 채우도록 중앙 기준으로 확대 (기본) |
| FIT_SCREEN | 이미지 전체가 보이도록 화면에 맞춤 |

### 불투명도

배경 텍스처의 불투명도를 조절할 수 있습니다. 슬라이더로 강도를 조정하면 배경이 은은하게 또는 선명하게 표시됩니다.

## 화면 설정

### 화면 유지

읽는 동안 화면이 자동으로 꺼지지 않게 합니다.

| 상태 | 동작 |
|------|------|
| OFF | 시스템 설정에 따라 화면 꺼짐 |
| ON | 뷰어에서 화면이 꺼지지 않음 |

> **주의**: 배터리 소모가 증가합니다.

---

## 버튼 동작 설정

뷰어 좌/우측 버튼의 동작을 설정합니다.

### 옵션

| 옵션 | 설명 |
|------|------|
| 이전/다음 페이지 | 페이지 이동 |
| 비활성화 | 버튼 사용 안 함 |

---

## 이름 표기 설정

캐릭터 이름의 표시 방식을 설정합니다.

### 옵션

| 옵션 | 표시 예시 |
|------|----------|
| 번역만 | 김철수 |
| 번역(원문) | 김철수(田中太郎) |
| 원문(번역) | 田中太郎(김철수) |

### 적용 범위

- 본문 내 캐릭터 이름
- 대화 화자 표시
- 캐릭터 팝업

## 권장 설정

### 일반 읽기

| 설정 | 값 |
|------|------|
| 폰트 크기 | 16sp |
| 폰트 패밀리 | 기본 |
| 줄 간격 | 1.5 |
| 문단 간격 | 보통 |
| 배경 | 시스템 색상 또는 밝은 종이 |
| 화면 유지 | ON |

### 장시간 읽기

| 설정 | 값 |
|------|------|
| 폰트 크기 | 18sp |
| 폰트 굵기 | 중간 |
| 줄 간격 | 1.8 |
| 문단 간격 | 넓게 |
| 배경 | 따뜻한 종이 또는 한지 |
| 텍스트 색상 | AUTO |
| 화면 유지 | ON |

### 어두운 환경

| 설정 | 값 |
|------|------|
| 폰트 크기 | 18sp |
| 폰트 굵기 | 중간 |
| 배경 | 다크 우드 또는 검은 한지 |
| 텍스트 색상 | LIGHT |
| 시스템 테마 | 다크 모드 |

## 문제 해결

### 폰트가 적용 안 됨

**해결**:
1. 앱 재시작
2. 다른 폰트 선택 후 다시 변경

### 설정이 저장 안 됨

**해결**:
1. 앱 권한 확인
2. 저장 공간 확인
3. 앱 재설치

### 화면 유지가 작동 안 함

**해결**:
1. 시스템 배터리 절약 모드 확인
2. 앱 배터리 최적화 제외 설정
