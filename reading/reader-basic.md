# 뷰어 기본 사용법

Transy 뷰어의 UI 구성과 기본 조작법을 안내합니다.

---

## 뷰어 화면 구성

### 화면 영역

| 영역 | 위치 | 설명 |
|------|------|------|
| **상단 바** | 상단 | 제목, 설정, 컨텍스트 버튼 |
| **본문 영역** | 중앙 | 소설 텍스트 표시 |
| **하단 바** | 하단 | 회차 이동, 번역, TTS 버튼 |

---

## 상단 바

### 버튼 설명

| 버튼 | 기능 |
|------|------|
| ← (뒤로) | 상세 화면으로 돌아가기 |
| 제목 | 현재 회차 제목 표시 |
| ⚙️ (설정) | 뷰어 설정 열기 |
| 📋 (목록) | 회차 목록 열기 |
| 📥 (프리패치) | 프리패치 상태 확인 및 제어 |

---

## 본문 영역

### 텍스트 표시

- **원문**: 번역 전 원본 텍스트
- **번역문**: AI로 번역된 텍스트

### 캐릭터 하이라이트

등록된 캐릭터 이름이 하이라이트되어 표시됩니다.

캐릭터 이름을 탭하면:
- 캐릭터 정보 팝업 표시
- 이름, 별명, 설명 확인 가능

---

## 하단 바

### 기본 버튼

| 버튼 | 기능 |
|------|------|
| ◀ (이전) | 이전 회차로 이동 |
| ▶ (다음) | 다음 회차로 이동 |

### 기능 버튼

| 버튼 | 기능 |
|------|------|
| 🌐 (원문/번역 전환) | 원문과 번역문 전환 |
| TTS | 음성 읽기 시작/정지 |

---

## 몰입 모드

읽기에 집중할 수 있도록 상단 바와 하단 바를 자동으로 숨기는 기능입니다.

### 진입 방법

| 동작 | 결과 |
|------|------|
| **스크롤 시작** | 자동으로 몰입 모드 진입 (바 숨김) |
| **본문 영역 탭** | 몰입 모드 토글 (숨김 ↔ 표시) |

### 자동 해제

다음 상황에서 몰입 모드가 자동으로 해제됩니다:
- **회차 전환** 시 (이전/다음 회차 이동)
- **텍스트 드래그 선택 모드** 진입 시

### 번역 진행도 표시

번역 중에는 진행 상황이 항상 화면 상단에 표시됩니다:
- **일반 모드**: 상단 바 아래에 진행률 바와 퍼센트 표시 (예: "청크 2/5 (40%)")
- **몰입 모드**: 화면 최상단에 반투명 배경으로 진행률 표시

> **참고**: 몰입 모드에서도 번역 진행도는 사라지지 않으므로, 번역 상태를 항상 확인할 수 있습니다.

---

## 프리패치 아이콘

상단 바에 항상 표시되는 프리패치 상태 아이콘입니다.

### 아이콘 상태

| 상태 | 표시 | 설명 |
|------|------|------|
| **비활성** | 회색 아이콘 | 미리받기 개수가 0으로 설정됨 |
| **대기(IDLE)** | 기본 아이콘 | 프리패치 준비 상태 |
| **진행중(ACTIVE)** | 애니메이션 + 진행률 | 다운로드/번역 진행 중 |
| **완료** | 완료 표시 | 설정된 개수만큼 완료 |
| **실패** | 오류 표시 | 프리패치 실패 |

### 아이콘 클릭

프리패치 아이콘을 탭하면:
- 프리패치 상태 시트가 열림
- 현재 진행 상황 상세 확인 가능
- 수동으로 시작/취소 가능

### 비활성 상태

미리받기 개수가 0으로 설정된 경우:
- 아이콘이 회색으로 표시됨
- 탭하면 설정 안내 다이얼로그 표시
- "소설별 설정에서 미리받기 개수를 1 이상으로 설정하세요" 안내

> 자세한 내용: [미리 받기](prefetch.md)

## 원문/번역 전환

번역된 상태에서 원문과 번역문을 전환할 수 있습니다.

### 표시 모드

| 모드 | 설명 |
|------|------|
| **번역문** | 번역된 텍스트 표시 (기본) |
| **원문** | 원본 텍스트 표시 |

전환 버튼(🌐)을 클릭하면 두 모드 사이를 토글합니다.

> **팁**: 번역 품질을 확인하거나 원문 표현을 참고할 때 유용합니다.

---

## 인증이 필요한 사이트

일부 소설 사이트는 로그인이나 캡차 인증이 필요합니다.

### 자동 인증 안내

원문 다운로드 시 인증이 필요하면 안내 다이얼로그가 표시됩니다.

### 인증 방법

1. "수동 확인" 버튼 클릭
2. WebView에서 로그인 또는 캡차 해결
3. 인증 완료 후 자동으로 콘텐츠 로드

### 지원하는 인증 유형

| 유형 | 설명 |
|------|------|
| 로그인 | 사이트 계정 로그인 |
| Cloudflare | 보안 검사 통과 |
| 캡차 | 이미지/reCAPTCHA 등 |

## 제스처 조작

### 스크롤

- **위/아래 스와이프**: 텍스트 스크롤
- 스크롤 시작 시 몰입 모드로 자동 전환 (상단/하단 바 숨김)

### 탭

- **본문 영역 탭**: 몰입 모드 토글 (바 숨김/표시 전환)
- **캐릭터 이름 탭**: 캐릭터 정보 표시

### 길게 누르기

텍스트를 길게 누르면:
- **복사**: 선택한 텍스트 복사
- **드래그 선택**: 범위 선택 모드
- **TTS 시작점**: 해당 위치부터 TTS 시작

## 회차 이동

### 이전/다음 버튼

하단 바의 ◀/▶ 버튼으로 회차를 이동합니다.

### 회차 목록

1. 상단의 목록 버튼(📋) 클릭
2. 전체 회차 목록 표시
3. 원하는 회차 선택

### 회차 상태 표시

| 상태 | 표시 |
|------|------|
| 미다운로드 | 흐리게 표시 |
| 다운로드됨 | 일반 표시 |
| 번역됨 | ✓ 표시 |
| 현재 회차 | 강조 표시 |

### 번역 완료 배지 실시간 반영

회차 목록에서 번역이 완료되면:
- 번역 완료 배지(✓)가 즉시 업데이트됨
- 새로고침 없이 실시간으로 상태 확인 가능
- 프리패치로 백그라운드 번역 중에도 완료된 회차는 즉시 표시됨

### 회차 제목 수정

회차 제목을 수동으로 수정할 수 있습니다.

1. 회차 목록에서 수정할 회차를 길게 누르기
2. "제목 수정" 다이얼로그 표시
3. **원본 제목**: 원래 회차 제목 (참고용, 수정 불가)
4. **번역된 제목**: 수정 가능한 입력 필드
5. 수정 후 "저장" 클릭

> **팁**: AI 번역이 회차 제목을 잘못 번역한 경우, 이 기능으로 직접 수정할 수 있습니다.

## 뷰어 설정

상단의 설정 버튼(⚙️)을 클릭하면 뷰어 설정이 열립니다.

### 빠른 설정 항목

| 설정 | 설명 |
|------|------|
| 폰트 크기 | 텍스트 크기 조절 |
| 줄 간격 | 줄 사이 간격 |
| 화면 유지 | 자동 꺼짐 방지 |

> 자세한 내용: [디스플레이 설정](display-settings.md)

---

## 이름 표기 설정

캐릭터 이름의 표기 방식을 설정합니다.

| 옵션 | 예시 |
|------|------|
| 번역만 | 사쿠라 |
| 번역(원문) | 사쿠라(桜) |
| 원문(번역) | 桜(사쿠라) |
| 첫 등장만 주석 | 첫 등장: 사쿠라(桜), 이후: 사쿠라 |

---

## 콘텐츠 다시 받기

원문 다운로드에 문제가 있을 경우:

1. 메뉴(⋮) 열기
2. "원문 재다운로드" 선택
3. 다시 다운로드 진행

---

## 번역 삭제

잘못된 번역을 삭제하고 다시 번역할 수 있습니다.

1. 메뉴(⋮) 열기
2. "번역 삭제" 선택
3. 확인 후 삭제
4. 번역 버튼으로 다시 번역

---

## 유용한 팁

### 끊김 없이 읽기

- "미리 받기" 기능을 활성화하면 다음 회차를 미리 준비
- 회차 전환 시 로딩 대기 시간 감소

### 장시간 읽기

- "화면 유지" 옵션을 켜면 화면이 꺼지지 않음
- 배터리 소모에 주의

### 눈 피로 감소

- 어두운 환경에서는 시스템 다크 모드 사용
- 적절한 폰트 크기 설정 (권장: 16-18sp)

## 문제 해결

### 텍스트가 너무 작음/큼

- 설정에서 폰트 크기 조절
- 시스템 폰트 크기 설정도 확인

### 원문 다운로드 실패

**해결**:
1. 인터넷 연결 확인
2. 사이트 접근 가능한지 확인
3. 인증이 필요한 경우 "수동 확인" 진행
4. "원문 재다운로드" 시도

### 캐릭터 하이라이트가 안 됨

- 캐릭터가 컨텍스트에 등록되어 있는지 확인
- 이름 철자가 일치하는지 확인
- 번역문 표시 모드인지 확인 (원문 모드에서는 미작동)

### 인증이 계속 필요함

- 파싱 룰에 인증 설정이 올바른지 확인
- 브라우저 쿠키가 유지되는지 확인
- 앱 재시작 후 다시 인증
