# 찾아바꾸기

번역된 텍스트에서 특정 단어나 문구를 검색하고 일괄 수정할 수 있습니다.

---

## 접근 방법

1. 뷰어 화면에서 상단 메뉴(⋮) 클릭
2. "찾아바꾸기" 선택

---

## 검색 범위

찾아바꾸기는 4가지 검색 범위를 제공합니다:

| 범위 | 설명 |
|------|------|
| **이번 화만** | 현재 읽고 있는 회차만 검색 (기본값) |
| **이전 화 포함** | 현재 회차부터 1화까지 모든 이전 회차 검색 |
| **다음 화 포함** | 현재 회차부터 마지막 회차까지 검색 |
| **전체 회차** | 소설의 모든 회차 검색 |

---

## 사용 방법

### 1단계: 검색

1. **검색 범위 선택**: 원하는 범위 칩을 탭
2. **검색어 입력**: "찾을 텍스트" 필드에 검색할 단어/문구 입력
3. **검색 버튼 클릭**: 번역된 텍스트에서 검색 실행

### 2단계: 결과 확인

검색이 완료되면:

- **총 발견 건수**: 상단에 전체 매칭 수 표시
- **회차별 결과**: 각 회차에서 발견된 건수 표시
- **미리보기**: 회차를 탭하면 해당 위치의 앞뒤 문맥 확인 가능

### 3단계: 선택적 바꾸기

각 검색 결과에는 체크박스가 있습니다:

- **전체 선택/해제**: 상단의 체크박스로 모든 항목 선택/해제
- **개별 선택**: 각 항목의 체크박스로 바꿀 항목만 선택

### 4단계: 바꾸기 실행

1. **바꿀 텍스트 입력**: "바꿀 텍스트" 필드에 새 단어/문구 입력
2. **일괄 바꾸기 클릭**: 선택된 모든 항목이 일괄 치환됨
3. **완료 확인**: 변경된 건수 표시

---

## 조사 자동 수정

한국어 번역에서 단어를 바꿀 때, 받침에 따라 조사가 어색해질 수 있습니다.

### 예시

"철수"를 "영희"로 바꿀 때:
- 수정 전: "철수**가** 왔다" → "영희**가** 왔다" (어색함)
- 수정 후: "철수**가** 왔다" → "영희**가** 왔다" (자연스러움)

### 지원 조사

| 조사 쌍 | 설명 |
|---------|------|
| 은/는 | 주제격 조사 |
| 이/가 | 주격 조사 |
| 을/를 | 목적격 조사 |
| 과/와 | 접속 조사 |
| 으로/로 | 방향/수단 조사 |
| 아/야 | 호격 조사 |
| 이다/다 | 서술격 조사 |

### 사용법

1. 조사 자동 수정 옵션은 한국어로 번역된 텍스트에서만 표시됩니다
2. "조사 자동 수정" 체크박스를 활성화하면 바꿀 단어의 받침에 맞게 조사가 자동 변경됩니다

---

## 주의사항

### 캐릭터 이름 검색 제한

> ⚠️ **중요**: 캐릭터 이름은 내부적으로 태그로 저장됩니다.

- "철수가", "철수를" 등 **조사가 붙은 형태로는 검색되지 않습니다**
- 캐릭터 이름 자체만 검색하면 찾을 수 있습니다

### 캐릭터 이름 변경 방법

캐릭터 이름을 변경하려면:
1. 찾아바꾸기 다이얼로그 내 "컨텍스트 관리로 이동" 링크 클릭
2. 또는 상단 바의 컨텍스트 버튼 → 캐릭터 탭에서 수정

> 캐릭터 이름을 컨텍스트에서 변경하면 모든 회차에 자동 반영됩니다.

---

## 활용 예시

### 번역 오류 수정

잘못 번역된 고유명사 일괄 수정:
- 검색: "마법사 길드"
- 바꾸기: "마법사 조합"

### 용어 통일

일관되지 않은 번역 통일:
- 검색: "스킬"
- 바꾸기: "기술"

### 오탈자 수정

반복되는 오탈자 일괄 수정:
- 검색: "햇습니다"
- 바꾸기: "했습니다"

## 문제 해결

### 검색 결과가 없음

**원인**:
- 검색어가 번역 텍스트에 없음
- 캐릭터 이름+조사 형태로 검색함

**해결**:
1. 검색 범위를 "전체 회차"로 확대
2. 캐릭터 이름은 조사 없이 검색
3. 번역 상태인 회차만 검색됨 (원문만 있는 회차는 미포함)

### 바꾸기가 적용되지 않음

**원인**:
- 선택된 항목이 없음
- 찾을 텍스트와 바꿀 텍스트가 동일

**해결**:
1. 체크박스로 바꿀 항목 선택
2. 바꿀 텍스트가 다른지 확인

### 조사가 어색하게 변경됨

**해결**:
- "조사 자동 수정" 옵션 활성화
- 한국어 번역에서만 작동
